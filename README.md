# 🚀 Extenshion OS

Extenshion OS is a Chrome Extension that brings multiple AI assistants into one place.

Instead of switching between different AI platforms, users can interact with multiple AI models like ChatGPT, Gemini, and Claude from a single workspace.

## ✨ Features

- 🤖 Multiple AI models in one place
- 🧠 Smart AI suggestion system
- 💬 Different response styles from each model
- 🎨 Modern dark AI-themed UI
- 🧩 Chrome Extension support

## 🛠️ Tech Used

- HTML
- CSS
- JavaScript
- Chrome Extension Manifest V3
